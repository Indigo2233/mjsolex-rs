# JSol’Ex Android 功能覆盖

以 Astro4j 提交 `7ffdaf5c` 的桌面版手册和源码为基准。Android 使用原生 Rust 界面和离线处理核心。各项以同一输入的参考结果和对应的移动端工作流通过测试作为完成条件。 [JSol’Ex 手册](https://github.com/melix/astro4j/blob/7ffdaf5c/docs/src/docs/asciidoc/en/jsolex.adoc) · [ImageMath 文档](https://github.com/melix/astro4j/blob/7ffdaf5c/docs/src/docs/asciidoc/en/imagemath.adoc)

| 功能组 | Android 当前覆盖 | 剩余功能及验收方式 |
|---|---|---|
| 单次扫描与文件 | 单色 SER，`JSOLEX-TRIMMED`，平均光谱，自动和手动拟合，像素偏移，PNG 和无 WCS 的 16 位 FITS 导出 | Bayer 与 RGB/BGR，错误位深探测，坏帧和元数据，其他输入与输出格式，SER 播放与裁切导出。用 Astro4j 各格式的原始样本和文件头核对像素及元数据。 |
| 几何与画质 | 完整太阳盘的扫描轴比例和剪切校正，拟合失败时保留原图，预览对比度拉伸 | 手动椭圆、翻转、旋转、太阳 P 角、自动裁切、饱和盘面、条带、锯齿、装架振荡、鬼影、去噪、锐化和可保存调整。用校正前后盘面参数与参考图验证。 |
| 光谱分析与图像产品 | 单条吸收线重建，按像素偏移重建另一波段 | 多条谱线同时重建，光谱图集和自动波长识别，光谱浏览器与 3D 调试，连续谱、着色、日珥、日食、多普勒图、太阳活动区、日迹标注和完整 FITS 元数据。用已知谱线和跨波段标准产品验证。 |
| 观测测量 | 现有偏移量和原始采样可供离线分析 | 光谱校准、红移、Ellerman 炸弹、耀斑、Hα 云模型、视频分析和曝光计算器。用已知速度、波长、曝光和模型参数验证。 |
| 批处理和观测管理 | 单文件导入与导出 | 预设、任务会话、批处理、往返扫描和条件翻转、任务中断恢复、目录观察、SunScan 导入和观测记录。用前后向扫描和任务中断后的重跑验证。 |
| 图像组合 | 单图重建与预览 | 连拍配准、堆栈、马赛克、拼贴和注释。用带已知平移、旋转、重叠率和坏帧的数据集验证。 |
| 脚本与互操作 | Rust 示例可从桌面调用与 App 共用的处理核心 | ImageMath 函数、参数、自定义函数、脚本仓库与版本兼容，Python 与批处理脚本能力，SDO 联查，嵌入式服务与实时谱线识别。用上游脚本、接口样例和结果文件回归。 |

建议移植顺序为输入和科学元数据，完整几何与坏像素校正，光谱标定与多波段产品，批处理和配准，最后扩展测量、脚本及设备互操作。每组单独维护真实观测、合成边界样本和 Android 资源开销基准。
